# Security policy

Oaken Trunk is pre-alpha software. Please report suspected vulnerabilities privately and
do not open a public issue.

Report it through GitHub's private vulnerability reporting for this repository:
<https://github.com/dfoulks1/oaken-trunk/security/advisories/new>.

Include what you found, how to reproduce it, and the version or commit. You can expect an
acknowledgement, and we will coordinate disclosure with you.
