Architecture

A map of the architecture pages.

  • Writing a plugin: base classes, capabilities, contract suites
  • Overview: layers, the operation registry, what trunk is not
  • API and CLI: one registry, the HTTP API, the CLI, MCP
  • Spool: the spool contract, the directory driver, durability, quotas
  • Process model: workers, threads, limits, shared state
  • Ingestion: HTTP, CLI, LMTP, SMTP, backpressure
  • Consumers: lease, fetch, ack, nack, notification
  • Mail authentication: DKIM, SPF, DMARC and ARC
  • Logs: diagnostics only, never content
  • Security: the request guard, signed requests, keys and replay protection
  • AI safety: rules and exposure tiers for anything a model can reach
  • Send: the outbound path and bursts
